Features

Meeting operations, without the manual cleanup.

Use slash commands inside your Discord server to run and document meetings with a consistent workflow.

📅 Scheduling

Create meetings, set reminders, choose channels and keep the server aligned on meeting times.

📋 Attendance

Track who joined, how long they attended, and export a structured attendance report.

🎙️ Recording

Capture meeting audio with a clear recording notice. Free supports up to 45 minutes per recording.

🧠 AI Notes

Pro adds AI transcription, meeting summaries, key discussion points, decisions and action items.

🧊 Server Setup

Configure default voice/report channels, timezone and attendance settings with an interactive setup panel.

🔒 Temporary Processing

Recording files are used temporarily for processing and delivery, then removed from Frost Scribe's temporary runtime storage.

How it works

A simple Discord-first workflow.

1. Configure

A server administrator runs /setup and selects the default voice channel, report channel and timezone.

2. Run the meeting

Start attendance or recording from Discord. Frost Scribe tracks the active session and produces the meeting outputs.

3. Receive results

Attendance reports and recording outputs are delivered back to Discord. Pro sessions also receive AI-generated notes.

Privacy & recording

Recording should always be transparent.

Frost Scribe displays a recording notice when a recording begins. Server administrators and meeting organizers are responsible for informing participants and obtaining any consent required by applicable law or platform rules.

Frost Scribe is designed to process recording files temporarily for delivery and, for Pro, transcription/summary generation. See the Privacy Policy for details.
